# --- Python-Based Student Management System ---

# Project Overview

The **Student Management System** is a web-based application developed using Python, Flask, and SQLite. It is designed to simplify and manage student-related academic activities through an organized and user-friendly platform.

The system provides separate login access for Trainers and Students. Trainers can manage student information, track attendance, create tests, and evaluate student performance. Students can view their details, check attendance, attempt tests, and access their results.

# Project Objectives

- To simplify student information management.
- To maintain and manage student attendance records.
- To provide an organized platform for trainers and students.
- To conduct online tests and evaluate student performance.
- To understand practical web application development using Python and Flask.

# Key Features

- **Trainer Login:** Secure login access for trainers.
- **Student Login:** Separate login access for students.
- **Student Management:** Manage and maintain student details.
- **Attendance Management:** Track student attendance records.
- **Test Management:** Create and manage student tests.
- **Online Test:** Allow students to attempt available tests.
- **Result Management:** Calculate and display student test results.

# Technologies Used

| Technology | Purpose |
|---|---|
| Python | Backend programming |
| Flask | Web application framework |
| SQLite | Database management |

# Project Architecture

The application follows a simple web-based architecture:

1. **Frontend:** User interface for trainers and students.
2. **Backend:** Python and Flask handle application logic and requests.
3. **Database:** SQLite stores student details, attendance, tests, and results.

# Installation and Setup

Follow these steps to run the project locally.

# 1. Clone the Repository

```bash
git clone https://github.com/ommore4015/Python-Student-Management-System.git
```

# 2. Navigate to the Project Directory

```bash
cd Python-Student-Management-System
```

# 3. Install Dependencies

```bash
pip install flask
```

If a `requirements.txt` file is available, you can install all dependencies using:

```bash
pip install -r requirements.txt
```

# 4. Run the Application

Run the main Flask application file (for example, `app.py`):

```bash
python app.py
```

# 5. Open in Browser

Open the local URL displayed in your terminal, usually:

```text
http://127.0.0.1:5000/
```
